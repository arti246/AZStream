# AZStream - Стриминг с Яндекс.Диска

Приложение для просмотра стримов с Яндекс.Диска в реальном времени.

## Возможности

- Просмотр стримов в реальном времени
- Масштабирование изображения (pinch-to-zoom)
- Автоматическое обновление кадров (каждые 3 секунды)
- Боковое меню для навигации
- Поворот экрана без остановки стрима

## Установка и настройка

### 1. Требования

- Android Studio Meerkat (2024.3.1) или новее
- Android SDK API 37+
- Аккаунт Яндекс.Диска
- Токен доступа к Яндекс.Диску

### 2. Получение токена Яндекс.Диска

1. Перейдите на [Яндекс.OAuth](https://oauth.yandex.ru/)
2. Создайте новое приложение
3. Выберите тип "Веб-сервис"
4. Укажите права доступа: `disk.read` (чтение диска)
5. После создания скопируйте **OAuth-токен**

### 3. Настройка проекта

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ваш-аккаунт/AZStream.git
2. **Настройте токен доступа:**
